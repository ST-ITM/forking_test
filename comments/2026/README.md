# 2026 student comments
 
Add one Markdown file in this folder, named after your GitHub username.
For example: YOUR-GITHUB-USERNAME.md
 
Write a short, friendly comment about the class, Git, or your day.
Use this format:
 
# YOUR-GITHUB-USERNAME
 
Your comment goes here.
 
## Contribution steps
 
1. Fork this repository, or synchronize your existing fork.
2. Clone your fork and create a topic branch from the updated main.
3. Add only comments/2026/YOUR-GITHUB-USERNAME.md.
4. Commit the file and push your topic branch to your fork.
5. Open a pull request targeting ST-ITM/forking_test main.
 
Do not edit either README or another student's file.
If you need to revise an open contribution, update your own file on
its existing topic branch and push again.
